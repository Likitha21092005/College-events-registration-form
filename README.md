College Events Registration System

Overview:
This project is a College Events Registration System that allows students to:

Browse and register for various college events

Submit their personal and academic information

Make payments via QR code or payment number

View final registration details and event information

Features:
1. Event Registration Page
Displays all available college events

Allows students to select events they want to participate in

Collects necessary student information for registration

2. Payment Page
Provides multiple payment options:

QR code scanning

Payment reference number

Payment confirmation

3. Information Page
Displays final registration confirmation

Shows all events the student registered for

Presents submitted student details

Provides event dates, times, and other relevant information
